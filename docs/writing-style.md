# 문장 다듬기

말투 규칙은 `CLAUDE.md` 4절이다. 이 문서는 그 위에서, AI가 쓴 티가 나는 문장 패턴을 걷어내는 목록이다.
출처는 [humanizer](https://github.com/blader/humanizer)가 정리한 [위키백과 "AI 글쓰기의 징후"](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing)이고, 한국어 기술 글에 실제로 나타나는 것만 추렸다.

## 어휘

| 걸리는 것 | 고치는 방향 |
|---|---|
| `핵심적인`, `필수적인`, `혁신적인`, `강력한` | 근거 없는 평가어. 무엇이 어떻게 되는지로 바꾼다 |
| `~의 세계`, `~생태계`, `~라는 지형` | 은유를 걷고 대상을 그대로 부른다 |
| `주목할 만하다`, `흥미롭게도` | 지운다. 흥미로우면 내용이 말한다 |
| `역할을 한다`, `~를 수행한다`, `~를 제공한다` | `이다`, `한다`. 우회 동사를 단순 동사로 |

## 구조

- **억지 3항 병렬을 만들지 않는다.** 셋을 채우려고 없는 항목을 지어내는 자리가 있다. 둘이면 둘만 쓴다.
- **`A가 아니라 B다`를 남용하지 않는다.** 대비가 실제로 필요할 때만. 아니면 B만 단언한다.
- **`~부터 ~까지`로 범위를 꾸미지 않는다.** 양 끝이 같은 축 위에 있지 않으면 거짓 범위다. 실제 항목을 나열한다.
- **문장 시작을 반복하지 않는다.** 같은 주어나 접속사로 세 문장이 연달아 시작하면 하나를 바꾼다.
- **소제목을 첫 문장이 되풀이하지 않는다.** 제목이 이미 말한 것은 지우고 바로 내용으로 들어간다.
- **다음에 할 말을 예고하지 않는다.** `이제 ~를 살펴보자`를 지우고 그냥 살펴본다.

## 주체와 확신

- **행위자를 지우지 않는다.** `~되어진다`, `~라고 알려져 있다`, `~로 여겨진다`. 누가/무엇이 하는지 밝힌다.
- **가짜 깊이를 넣지 않는다.** `본질적으로`, `결국 핵심은`, `사실 솔직히 말하면`. 문장에서 지워도 뜻이 그대로면 군더더기다.
- **제기되지 않은 반론을 미리 방어하지 않는다.** 안 쓸 대안을 늘어놓고 기각하는 문단도 마찬가지다.
- **한정어를 겹치지 않는다.** `일반적으로 다소 어느 정도` 중 하나만 남긴다. CLAUDE.md 4절의 추측/사실 구분과 다른 얘기다. 추측 표기는 하나로 충분하다.

## 군더더기

| 걸리는 것 | 고치는 방향 |
|---|---|
| `~하기 위해서는` | `~하려면` |
| `~라는 사실 때문에` | `~때문에` |
| `~을 진행한다`, `~을 실시한다` | 동사 하나로 |
| `~할 수 있다는 점에서` | 잘라내고 결과만 |

## 서식

- 굵은 글씨는 문단당 한 곳까지. 산문 문단에서 강조가 두 번 이상 나오면 하나로 줄인다.
- 목록에 `**라벨**: 설명` 꼴을 억지로 만들지 않는다. 라벨이 실제 용어 이름인 「용어 정리」류는 그대로 둔다.
- 이모지를 쓰지 않는다.
- em dash(`—`)는 본문 문장 안에서만 걷어낸다. 쉼표, 괄호, 마침표로 갈라진다. 링크 제목, 표 안, 제목의 부제는 그대로 둔다.

## 맺음

막연한 격려로 끝내지 않는다. `~을 이해하면 더 나은 개발자가 된다`, `앞으로가 기대된다` 같은 문장은 지운다.
마지막 문장은 구체적 사실이거나, 다음에 무엇을 볼지에 대한 판단이다.

## 다듬는 순서

1. **표시한다.** 위 항목에 걸리는 곳을 먼저 전부 찾는다.
2. **문장째 다시 쓴다.** 단어만 바꿔 끼우면 뼈대가 그대로 남는다.
3. **대조한다.** 다시 쓰면서 이름·숫자·날짜·인용이 빠지거나 새로 생기지 않았는지 원본과 맞춘다.
