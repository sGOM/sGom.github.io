# 최종 검수 목록

체크된 글은 **사용자가 직접 전체 내용을 읽고 납득·이해한 상태**다.
체크된 글은 사용자가 그 글을 명시적으로 지목하지 않는 한 수정하지 않는다.
오탈자·링크·스타일 정리 같은 사소한 수정도 포함이다.

발행한 글과 `_drafts/`의 초안을 한 목록에서 같이 본다. 초안은 줄 끝에 `(초안)`을 달고 `_drafts/` 경로를 가리킨다.
